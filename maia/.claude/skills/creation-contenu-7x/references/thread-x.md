# Thread Twitter/X

Format pour se positionner comme référence sur un sujet. Un thread bien construit génère des retweets et des bookmarks, qui sont les deux signaux qui portent le plus loin sur X.

Note de contexte : Magalie n'est pas active sur X aujourd'hui, son audience est sur Facebook. Ce format sert donc principalement à décliner un contenu qui a déjà fonctionné ailleurs, plutôt qu'à construire une audience de zéro. Si elle demande un thread sans contenu source, signale-lui en une ligne que l'effort serait probablement mieux investi sur Facebook, puis écris quand même le thread : c'est sa décision, pas la tienne.

## Structure : 8 tweets

### TWEET 1 : le hook
- 280 caractères maximum
- Un teaser puissant et une promesse claire de ce qui suit
- Un chiffre ou un fait marquant si possible
- Termine par "Un thread 🧵" ou "Thread 👇"

### TWEETS 2 à 7 : le contenu
- Une seule idée par tweet
- Commence chaque tweet par une accroche courte
- 2 à 3 phrases courtes maximum
- Des sauts de ligne pour aérer

La règle qui compte : **chaque tweet doit pouvoir être retweeté seul**. C'est ce qui multiplie la portée, parce que les gens partagent rarement un thread entier, ils partagent le tweet qui les a marqués. Un tweet qui n'a pas de sens sorti de son contexte est un tweet perdu.

### TWEET 8 : conclusion et CTA
- Un récap ultra-rapide
- Un CTA clair : suivre, retweeter, sauvegarder, ou cliquer un lien
- Une touche personnelle du type "Si ce thread t'a aidé..."

## Règles d'écriture

- 280 caractères maximum par tweet, sans exception
- Phrases ultra-courtes
- Sauts de ligne stratégiques : sur X, le blanc est aussi important que le texte
- 1 à 2 émojis maximum par tweet
- Des chiffres et des listes
- Ton direct : "Tu", "Toi", "Ta"
- Pas de tirets longs

## Format de sortie

Numéro du tweet, puis le contenu exact prêt à copier-coller. Sépare chaque tweet par une ligne `---`.

Indique le nombre de caractères de chaque tweet entre parenthèses après le numéro, pour qu'elle vérifie d'un coup d'œil qu'aucun ne dépasse.
